# 버거 키오스크
## 개요
- c# 프로그래밍 학습
- 1줄 소개: 버거와 추가옵션을 원하는 대로 주문하는 화면 구현
- 사용한 컨트롤: Label, RadioButton, Checkbox, GroupBox, listBox, PictureBox, Button
- 사용한 플랫폼: c#, .NET windows Forms, Visual Studio, Github
- 사용한 기술과 구현한 기능: visual studio를 이용하여 UI 디자인

## 실행화면 (과제1)
- 과제1 코드의 실행 스크린샷
![과제1 실행화면] (img/과제1.png)
                  (img/스크린샷-1.png)

- 과제 내용
UI 구성: RadioButton, CheckBox, GroupBox를 활용한 시각적 배치.
데이터 추출: 사용자가 선택한 항목(텍스트)과 가격 정보를 가져오는 기능.
기능 구현: 주문하기(결과 출력) 및 초기화(선택 해제) 버튼 로직 작성.

- 구현 내용과 기능설명
사용자가 라디오 버튼이나 체크박스를 체크하면 해당 항목의 텍스트와 가격 정보를 가져옵니다. 주문하기 버튼을 누르면 선택된 모든 메뉴 이름과 합산된 전체 금액이 결과창에 나타납니다. 그룹박스를 통해 식사류와 음료류 등을 시각적으로 분리하여 사용자가 혼동 없이 선택할 수 있도록 설계합니다.


## 실행화면 (과제2)
- 과제2 코드의 실행 스크린샷
![과제2 실행화면] (img/과제2.png)

- 과제 내용
사용자가 아무런 메뉴도 선택하지 않은 상태에서 '주문하기' 버튼을 누를 경우를 대비합니다.
주문하기 버튼을 누르면 ‘메뉴를 선택하세요’의 메시지를 나오게 합니다.

- 구현 내용과 기능설명
이미지 예시와 같이 에러 메시지는 보통 눈에 잘 띄는 색상으로 설정하여 사용자가 즉각적으로 인지할 수 있도록 구현합니다.
선택된 항목이 하나도 없을 경우, 미리 배치해둔 Label의 Text 속성에 "메뉴를 선택해 주세요"와 같은 안내 문구를 할당합니다.
정상적으로 항목이 선택되어 주문이 진행될 때는 해당 Label의 텍스트를 다시 비우거나, 성공 메시지로 변경하여 사용자에게 현재 상태를 정확히 알립니다.

## 실행화면 (과제3)
- 과제3 코드의 실행 스크린샷
![과제3 실행화면] (img/과제3.png)

- 과제 내용
키보드 접근성 강화: 마우스 조작 없이 키보드 입력만으로 모든 주문 과정을 마칠 수 있도록 인터페이스를 개선합니다.
포커스 이동 설정: Tab 키와 방향키를 사용하여 각 메뉴 그룹과 세부 항목 사이를 자유롭게 이동할 수 있게 합니다.

- 구현 내용과 기능설명
속성을 조정하여 Tab 키를 누를 때 GroupBox 간에 순차적으로 포커스가 이동하도록 설정합니다.
탭 선택 순서를 논리적으로 구성하여 사용자가 메뉴 그룹과 항목을 쉽게 탐색할 수 있도록 합니다.
enter 이벤트를 활용하여 사용자가 라디오 버튼이나 체크박스에 포커스가 있을 때 Enter 키를 눌러 선택할 수 있도록 구현합니다. 이를 통해 마우스 없이도 주문 과정을 원활하게 진행할 수 있도록 합니다.

## 실행화면 (과제4)
- 과제4 코드의 실행 스크린샷
![과제4 실행화면] (img/과제4.png)

- 과제 내용
    - RadioButton과 CheckBox의 텍스트에 가격 정보를 추가하여 사용자가 메뉴 선택 시 가격을 쉽게 인지할 수 있도록 개선합니다.
    메뉴를 선택할 때마다 가격 정보를 명확히 표시하여 사용자가 주문 과정에서 가격을 쉽게 비교하고 선택할 수 있도록 합니다.

- 구현 내용과 기능설명
    - 각 RadioButton과 CheckBox의 Text 속성에 메뉴 이름과 함께 가격 정보를 포함시킵니다. 예를 들어, "치즈버거 - 5000원"과 같이 표시하여 사용자가 메뉴 선택 시 가격을 명확히 알 수 있도록 합니다. 이를 통해 사용자는 주문 과정에서 가격을 쉽게 비교하고 선택할 수 있습니다.
    - ListBox 내역 관리: 새로운 메뉴가 선택될 때마다 기존 리스트를 비우고(Clear), 현재 선택된 모든 항목을 다시 한 줄씩 추가합니다.
    - 선택된 가격으로 총 금액 계산: 각 메뉴 항목의 가격을 변수에 저장하고, 주문하기 버튼을 누를 때마다 선택된 항목들의 가격을 합산하여 총 금액ㅇ을 계산합니다. 계산된 총 금액은 결과창에 명확히 표시되어 사용자가 주문의 최종 금액을 쉽게 확인할 수 있도록 합니다.
