# 버거 키오스크
## 개요
- c# 프로그래밍 학습
- 1줄 소개: 버거와 추가옵션을 원하는 대로 주문하는 화면 구현
- 사용한 컨트롤: Label, RadioButton, Checkbox, GroupBox, listBox, PictureBox, Button
- 사용한 플랫폼: c#, .NET windows Forms, Visual Studio, Github
- 사용한 기술과 구현한 기능: visual studio를 이용하여 UI 디자인

## 실행화면 (과제1)
- 과제1 코드의 실행 스크린샷
![과제1 실행화면] (img/과제1.png)
                  (img/스크린샷-1.png)

- 과제 내용
UI 구성: RadioButton, CheckBox, GroupBox를 활용한 시각적 배치.
데이터 추출: 사용자가 선택한 항목(텍스트)과 가격 정보를 가져오는 기능.
기능 구현: 주문하기(결과 출력) 및 초기화(선택 해제) 버튼 로직 작성.

- 구현 내용과 기능설명
사용자가 라디오 버튼이나 체크박스를 체크하면 해당 항목의 텍스트와 가격 정보를 가져옵니다. 주문하기 버튼을 누르면 선택된 모든 메뉴 이름과 합산된 전체 금액이 결과창에 나타납니다. 그룹박스를 통해 식사류와 음료류 등을 시각적으로 분리하여 사용자가 혼동 없이 선택할 수 있도록 설계합니다.


## 실행화면 (과제2)
- 과제2 코드의 실행 스크린샷
![과제2 실행화면] (img/과제2.png)

- 과제 내용
사용자가 아무런 메뉴도 선택하지 않은 상태에서 '주문하기' 버튼을 누를 경우를 대비합니다.

- 구현 내용과 기능설명
이미지 예시와 같이 에러 메시지는 보통 눈에 잘 띄는 색상으로 설정하여 사용자가 즉각적으로 인지할 수 있도록 구현합니다.
선택된 항목이 하나도 없을 경우, 미리 배치해둔 Label의 Text 속성에 "메뉴를 선택해 주세요"와 같은 안내 문구를 할당합니다.
정상적으로 항목이 선택되어 주문이 진행될 때는 해당 Label의 텍스트를 다시 비우거나, 성공 메시지로 변경하여 사용자에게 현재 상태를 정확히 알립니다.
